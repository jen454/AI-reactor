# AI 에이전트 한도 트래커 (가칭) — 작업 지시서

## 0. 이 문서를 읽는 방법

한 번에 다 만들라는 요청이 아니다. 아래 **마일스톤 순서대로** 진행하고,
각 마일스톤이 끝날 때마다 멈춰서 무엇을 만들었고 어떻게 확인하면 되는지 보고해라.
내가 확인하기 전에는 다음으로 넘어가지 마라.

**12장은 실제 기기에서 측정·확인한 사실이다.** 추측과 구분하기 위해 분리해 두었고,
본문과 충돌하는 지점은 거기에 명시돼 있다.

## 1. 만들려는 것

macOS 메뉴바에 상주하면서 Claude Code와 Codex의 남은 한도를 보여주는 앱.

- **메뉴바** — 아이콘 하나로 "지금 신경 써야 하나"만 전달
- **팝오버** — 프로바이더별 세션/주간 잔량과 리셋 시각
- **아이콘 팩** — 잔량을 어떤 형태로 볼지 사용자가 고른다
  (연료 계기판, 물컵, 세그먼트 바, 배터리 등)

### 수익 모델과 그 영향

앱 본체는 **무료**다. 나중에 아이콘 팩을 유료로 판다.
그래서 **아이콘 시스템의 확장성이 이 앱에서 가장 중요한 설계 결정**이다 (5장).

1차 범위에는 결제, 라이선스 검증, 코드 서명이 들어가지 않는다.
쓰는 사람이 생긴 뒤에 붙인다.

### 하지 않는 것

- 소진 시점 예측 — 기본 제공 정보만 쓴다
- 사용 이력 저장, 그래프
- 캐릭터, 애니메이션, 데스크톱 펫
- Windows — 맥에서 구조 확정 후
- 결제, 라이선스

## 2. 기술 스택

- **Tauri v2** (Rust 백엔드 + 시스템 웹뷰)
- 프론트: **React + TypeScript + Vite**
- 상태관리 라이브러리 없이 React 내장으로 충분하다. 과설계하지 마라
- 나는 프론트엔드 개발자다. **Rust 코드를 쓸 때는 왜 그렇게 쓰는지 반드시 설명을 붙여라**
- macOS 전용. 플랫폼 의존 코드는 나중에 확장할 수 있게 한곳에 몰아둬라

### 성능은 기능이다

같은 문제를 푸는 앱 하나가 Electron에서 네이티브로 이주했다. 유휴 오버헤드가 이유였다.
**마일스톤 1이 끝나는 즉시 유휴 CPU와 메모리를 측정해 보고해라.**
이후 마일스톤마다 다시 재고, 눈에 띄게 오르면 먼저 알려라.

## 3. 데이터 레이어

**인터페이스부터 정의**하고 구현체를 갈아끼울 수 있게 만들어라.

```ts
type LimitWindow = {
  kind: 'session' | 'weekly';
  remainingPercent: number;   // 잔량 기준. 사용률 아님
  resetsAt: Date;
};

type ProviderSnapshot = {
  provider: 'claude' | 'codex';
  windows: LimitWindow[];
  capturedAt: Date;
  status: 'ok' | 'stale' | 'expired' | 'not_installed' | 'error';
};

interface UsageProvider {
  id: string;
  isInstalled(): Promise<boolean>;
  fetch(): Promise<ProviderSnapshot>;
}
```

**모든 수치는 잔량 기준으로 통일한다.** 사용률과 잔량을 섞으면 화면에서 방향이 엇갈린다.

> **창 종류에 대한 주의 (12장 참조).** 실측 결과 Codex의 창은 43200분(30일)이라
> `session` 도 `weekly` 도 아니다. 내부 식별자는 **창 길이(분)** 로 두고,
> `session` / `weekly` / `monthly` 는 그 길이에서 유도한 표시용 라벨로 쓴다.
> 두 종류로 고정하면 첫 번째 다른 플랜에서 깨진다.

### Claude — OAuth 사용량 엔드포인트

로컬 로그에는 토큰 개수만 있고 한도 정보가 없다. 엔드포인트를 읽어야 한다.

토큰은 `claude` CLI가 저장해둔 것을 **읽기만** 한다.
키체인 항목 `Claude Code-credentials`, 없으면 `~/.claude/.credentials.json`.

#### 절대 하지 말 것 — 토큰 갱신

**토큰 갱신 엔드포인트를 호출하지 마라.** refresh token이 회전하기 때문에,
우리 앱이 CLI의 복사본으로 갱신하면 CLI 토큰이 무효화되고
사용자가 다음에 `claude`를 실행할 때 로그아웃된다.

**자격증명의 소유자는 CLI 하나뿐이고, 갱신도 CLI만 한다.**
만료되면 갱신을 시도하지 말고 `status: 'expired'` 를 반환해라.

#### 그 외

- 문서화된 공개 API가 아니다. **어댑터 뒤에 격리**하고 실패를 정상 경로로 다뤄라
- 실패 시 마지막 성공 스냅샷을 `stale` 로 반환한다. 크래시나 빈 화면은 안 된다
- 429는 사용량 조회 자체의 제한이다(한도 소진은 200 + utilization 100으로 온다). `Retry-After`만큼 쉬되(최소 30초) 다음 3분 폴링을 넘기지 마라. 창 리셋까지 멈추면 게이지가 몇 시간 동안 멈춘다. 네트워크·서버 오류 백오프도 같은 상한을 따른다 — Claude와 Codex 모두 3분마다 반드시 다시 조회한다

### Codex — 로컬 세션 로그

`~/.codex/sessions/**/*.jsonl` 의 `token_count` 이벤트 안에
서버가 준 `rate_limits` 스냅샷이 그대로 들어 있다 (사용률, 창 길이, 리셋 시각).
네트워크도 자격증명도 필요 없다.

가장 최근 스냅샷을 쓰되 **기록 시각을 함께 보관해라.** Codex는 실행 중일 때만
한도를 기록하므로 값이 낡을 수 있다. 일정 시간이 지나면 `stale` 이다.

### 설치 여부 판정

해당 CLI의 디렉터리나 자격증명이 없으면 `not_installed` 다.
**하나만 설치돼 있어도 앱은 온전히 동작해야 한다.**

## 4. 메뉴바

- **아이콘만 띄운다. 숫자는 붙이지 않는다** (2026-09-15 결정).
  게이지가 곧 수치고, 옆에 퍼센트를 쓰면 같은 말을 반복하면서 폭만 먹는다.
  정확한 숫자를 원하는 사람은 이미 팝오버를 여는 중이다
- 아이콘은 항상 **가장 급한 창 하나**를 표시한다.
  두 프로바이더를 한 아이콘에 세로로 쌓으면 8pt씩이라 형태가 뭉개진다
- `not_installed` 프로바이더는 메뉴바에 나타나지 않는다

### 조용한 기본값

기존 앱들은 게이지마다 초록 뱃지를 단다. 전부 초록이면 신호 역할을 못 하고,
정작 하나가 위험해질 때 묻힌다.

**정상은 무표시가 기본이다. 강조는 나빠질 때만 등장한다.**

## 5. 아이콘 팩 시스템 (핵심 설계)

아이콘을 **코드에 박지 마라.** 데이터로 분리한다.
나중에 팩을 추가할 때 앱 수정이 필요 없어야 하고, 잠금 처리가 플래그 하나여야 한다.

### 구조

```
icons/
  segment-bar/
    manifest.json
    level-5.svg   // 잔량 81–100%
    level-4.svg   // 61–80%
    level-3.svg   // 41–60%
    level-2.svg   // 21–40%
    level-1.svg   // 1–20%
    level-0.svg   // 0%
    expired.svg   // 만료·오래됨
  fuel-gauge/
  water-cup/
  battery/
```

manifest에는 최소한 `id`, `displayName`, `author`, `isTemplate`, `levels` 를 둔다.
앱은 `icons/` 를 스캔해서 목록을 만든다. 하드코딩된 목록을 두지 마라.

### 아이콘 제작 규칙

- **흑백 템플릿 이미지.** macOS가 다크·라이트 모드와 강조색에 자동으로 맞춘다.
  색을 쓰면 직접 대응해야 한다
- **색으로 경고하지 않는다.** 형태로 구분한다
- 잔량은 **6단계로 양자화**한다. 연속 값으로 그리면 16×16에서 차이가 안 보인다
- 작은 크기에서는 **개수형**(세그먼트, 점)이 가장 잘 읽히고, 면적형(물컵, 배터리)이
  그다음이다. **각도형**(바늘, 도넛)은 메뉴바에서 잘 안 읽히니 주의해서 그린다

### 1차 동봉 팩

**기본값은 아크 리액터형 패널 링이다** (2026-09-17 결정, `fuel-gauge`를 대체).
`segment-bar` 와 `water-cup` 을 함께 넣는다.

> 여기까지 세 번 실측했다.
>
> **1차 — 바늘 계기판.** 바늘만으로는 0%와 20%가 1760px 중 **65px** 차이밖에
> 안 났다 — 신호가 아니라 미동이다. 스윕을 160°로 넓히고 잔량만큼 차오르는
> 굵은 호를 더하고 바늘을 가장 무겁게 그려서 겨우 넘겼다.
>
> **2차 — 연속 충전 링.** 아크 리액터 요청을 받고, SPEC 5장이 바늘과 같은
> 문단에서 도넛형도 "잘 안 읽힌다"고 콕 집었다는 걸 확인한 뒤 같은 방식으로
> 다시 쟀다. 360°를 다 쓰므로 한 단계가 72°(바늘의 32°보다 넓다)라
> `neighbouring_levels_are_distinguishable` 은 첫 시도에 통과했다. 그런데
> 사용자가 다시 보고 "테두리가 여러 칸으로 나뉘어서 비율만큼 빈칸이 되는"
> 모양을 요청했다 — 연속으로 차오르는 모양은 legibility는 통과해도 "패널이
> 몇 개 켜졌나"가 안 보이고 로딩 스피너처럼 읽혔던 것이다.
>
> **3차 — 지금의 패널 링.** 세그먼트 바·바나나 개수에서 이미 검증된 "개수형은
> 단계당 변화가 크다"는 성질을 원형으로 옮겼다. 5개 패널을 26° 간격으로 처음
> 그렸더니 **간격이 화면에 전혀 안 보였다.** 원인은 실제 버그였다 —
> `Canvas::arc` 가 `width` 파라미터를 반지름으로 그대로 넘기고 있어서, 굵기
> 4.2로 지정한 게 실제로는 지름 8.4로 그려졌고 이웃 패널의 둥근 끝(캡)끼리
> 서로 먹어치워 5개가 다시 하나의 링으로 뭉쳤다. 표면적인 간격 각도를 늘리는
> 임시방편 대신 `width`가 반지름이 아니라 스트로크 굵기를 뜻하도록 근본
> 수정을 하고 나서야 5개 패널이 뚜렷이 갈라져 보였다.
>
> 다 채워진 링(레벨5)이 빈 링(레벨0)보다 잉크 반지름이 조금 더 넓게 나오는
> 것도 실측으로 확인했다 — 켜진 패널이 꺼진 패널보다 굵어서 생기는 차이다.
> 다만 `render()` 는 항상 44×44 고정 버퍼를 반환하므로 macOS가 잡는 아이콘
> 크기 자체는 레벨과 무관하게 그대로다. 실제로 이웃 아이콘이 밀릴 위험은
> 없고, 테스트는 그 실제 제약(캔버스 크기 불변)을 정확히 검증하도록 고쳤다.
**처음부터 많이 만들지 마라.** 하나를 제대로 만들고 나머지는 변형이다.
마일스톤 6 전까지는 단색 도형 플레이스홀더로 둔다.

## 6. 팝오버

폭 340pt. 위에서 아래로:

1. **프로바이더 카드** — 프로바이더당 한 장. 안에 세션/주간 게이지 두 개,
   각각 잔량 %와 리셋까지 남은 시간
2. **하단** — 새로고침, 설정(아이콘 선택)

- 프로바이더 식별용 로고(Claude, OpenAI)는 **어느 프로바이더인지 알려주는
  용도로** 쓴다 — 팝오버 카드의 작은 아이콘, 그리고 메뉴바 게이지 안의 마크.
  (2026-09-19 결정: 비상업 오픈소스이고, 로고는 "이 게이지가 무엇을 재는가"를
  가리키는 데만 쓰므로 허용. 원래는 카드 안에서만 쓰게 돼 있었다.)
  앱 이름·앱 아이콘·앱 브랜딩에는 여전히 쓰지 않는다 — 앱 아이콘은 우리 게이지
  모양(`assets-src/app-icon.png`)이다
- Codex 카드에는 **스냅샷 시각**을 함께 적는다. 숨기면 앱이 거짓말을 하게 된다

### 세 가지 빈 상태

생김새가 비슷하지만 사용자가 할 행동이 전부 다르다. **뭉뚱그리지 마라.**

| 상태 | 표시 | 사용자가 할 일 |
|---|---|---|
| 로딩 | 스켈레톤 (움직이는 회색) | 기다린다 |
| `not_installed` | 흐린 빈 카드 | 없음 |
| `expired` / `stale` | 마지막 값 흐리게 + 안내 | `claude` 한 번 실행 |

**`not_installed` 에 스켈레톤을 쓰지 마라.** 스켈레톤은 "곧 로드된다"는 관습이라
영영 오지 않을 데이터를 기다리게 만든다. 정적인 빈 카드를 써라.

빈 카드 문구는 결핍처럼 읽히지 않게. "Codex 없음"이 아니라
"Codex를 쓰면 여기에 함께 표시됩니다". 하나만 쓰는 사용자에게
앱이 반쪽으로 느껴지면 안 된다.

`expired` 안내는 에러처럼 보이면 안 된다.
"`claude`를 한 번 실행하면 다시 연결됩니다" 정도로.

## 7. 성능 규칙

- 팝오버가 **닫혀 있으면 3분**, **열려 있으면 30초** 주기로 갱신
  (2026-09-17 결정, 원래는 60초/10초). **여는 순간은 항상 즉시 조회**하므로
  닫힘 주기는 메뉴바 아이콘 자체의 최신성에만 영향을 준다 — 열었을 때 보는
  숫자는 이 값과 무관하다. (10초는 실측에서 7회 만에 429를 부른다 — 12장)
- 아이콘은 **단계가 바뀔 때만** 다시 그린다. 매 틱마다 그리지 마라
- 애니메이션은 쓰지 않는다. 정적 아이콘이다
- 유휴 상태에서 CPU 사용률이 눈에 띄면 그건 버그다

## 8. 지켜야 할 선

- **토큰을 갱신하지 마라** (3장). 가장 중요하다
- 사용자 파일에 쓰기 금지. `~/.claude` 와 `~/.codex` 는 **읽기 전용**이다
- 자격증명을 우리 앱의 설정 파일이나 로그에 기록하지 마라. 메모리에만 둔다
- Anthropic, OpenAI의 로고와 상표를 앱 이름·앱 아이콘·브랜딩에 쓰지 마라.
  프로바이더를 가리키는 표시(팝오버 카드, 메뉴바 게이지 안의 마크)로는 쓴다 — 6장.
  README에 비공식 앱임을 밝힌다
- 다른 앱의 에셋이나 코드를 복사하지 마라
- 우리 서버로 아무것도 전송하지 마라. 전부 로컬에서 동작한다

## 9. 마일스톤

1. **뼈대** — Tauri v2 프로젝트, Dock 아이콘 없는 메뉴바 전용 앱,
   고정 아이콘 + 빈 팝오버. 끝나면 유휴 CPU·메모리 측정 보고
2. **자격증명 로딩** — 키체인/파일에서 토큰 읽기, 만료 판정, 설치 여부 판정.
   **네트워크 호출은 아직 하지 않는다.** 만료·부재 케이스를 먼저 다뤄라
3. **Claude 프로바이더** — 한도 조회, 스냅샷을 콘솔에 출력.
   실패·429·만료 경로를 전부 테스트해라
4. **Codex 프로바이더** — 세션 로그 파서, 스냅샷 시각 보관, 낡음 판정
5. **팝오버 UI** — 프로바이더 카드, 게이지, 리셋 카운트다운, 세 가지 빈 상태
6. **아이콘 팩 시스템** — 스캔·로딩, 6단계 매핑, 설정에서 선택, 메뉴바 연동
7. **다듬기** — 소진 임박 알림 1회, 로그인 시 자동 실행

마일스톤 2를 3에서 분리한 이유는 자격증명 처리가 이 앱에서 가장 위험하기 때문이다.
여기서 실수하면 내 `claude` 로그인이 날아간다. 따로 확인하고 넘어간다.

> **진행 상황 (11장).** 1~4는 이미 구현·검증돼 있다. 5는 대부분 되어 있고
> 새 기획에 맞춘 조정이 필요하다. 6이 이번 개정의 실질적인 새 작업이다.

## 12. 실측으로 확인된 것

추측이 아니라 이 기기에서 직접 확인한 사실. 본문과 충돌하는 곳은 표시했다.

### Claude — OAuth 사용량 엔드포인트

```
GET https://api.anthropic.com/api/oauth/usage
Authorization: Bearer <access token>
```
```json
{ "five_hour": { "utilization": 63, "resets_at": "2026-09-11T04:00:01.028710+00:00" },
  "seven_day": { "utilization": 34, "resets_at": "..." } }
```

- **`utilization` 은 이름과 달리 이미 퍼센트(0–100)다.** 0~1 분수가 아니다.
  CLI 코드에 보이는 `utilization * 100` 은 파이프라인 뒤쪽 내부 구조체를
  다루는 것이지 이 응답이 아니다. 여기서 한 번 속았고, clamp가 그 오류를
  "모든 창 100%"로 감췄다
- **`resets_at` 은 RFC 3339 문자열.** 숫자(Unix 초)도 받아들이게 해 뒀다
- 키체인 항목의 account는 **macOS 사용자명**이라 하드코딩 금지. service로만 조회한다
- **⚠️ 10초 주기로 치면 약 7회 만에 429.** 7장이 요구하는 10초는 실측에서
  깨진다. 게다가 이 계정은 `claude` CLI와 CI가 같이 쓰므로 우리 폴링이
  사용자의 실제 작업과 경쟁한다. **30초가 실용 하한**이고, 여는 순간
  즉시 조회하므로 체감은 같다

### Codex — 세션 로그

`~/.codex/sessions/<년>/<월>/<일>/rollout-*.jsonl` 의 `token_count` 이벤트:

```jsonc
// 한도가 있는 플랜
"rate_limits": { "plan_type": "go",
  "primary": { "used_percent": 100.0, "window_minutes": 43200, "resets_at": 1783127522 },
  "secondary": null }

// 구독 없음 — 이 기기의 현재 상태
"rate_limits": { "limit_id": "premium", "plan_type": null,
  "primary": null, "secondary": null,
  "credits": { "has_credits": false, "unlimited": false } }
```

- `used_percent` 0–100, `resets_at` **Unix 초**
- **⚠️ `window_minutes` 가 43200(30일)이다.** `session` 도 `weekly` 도 아니다.
  3장의 두 종류 고정은 여기서 깨진다
- **⚠️ 창이 전부 null인 기록이 존재한다.** 로그인은 돼 있는데 구독이 없는 상태로,
  `not_installed` 도 `error` 도 아니다. "이 계정에 표시할 한도가 없음"이라는
  별도 안내가 필요하다. 더 뒤 기록으로 걸어가면 이미 없는 플랜의 숫자를
  현재처럼 보여주게 되므로 거기서 끊어야 한다
- **최신 스냅샷의 리셋 시각이 이미 지난 경우가 있다.** 이건 "낡음"이 아니라
  그 창이 이미 갈아엎어졌다는 뜻이라, 흐리게라도 보여주면 거짓말이 된다
- IDE 연동 모드(app-server)로 쓰면 롤아웃 파일을 안 남긴다. CLI 세션만 기록된다

### 플랫폼

- 키체인 `OSStatus -25320` = `errSecInDarkWake`. 화면이 잠든 저전력 상태라
  허용 창을 못 띄운 것이다. 실패가 아니라 "지금은 물어볼 수 없음"이므로
  거부처럼 래치하면 안 된다
- 메뉴바 아이콘 1프레임 갱신 ≈ **3.3ms** (메인 스레드 블로킹).
  7장이 애니메이션을 금지한 건 옳다 — 9fps 연속이면 CPU 5.5%였다
- 자체 서명 인증서로는 키체인 프롬프트가 안 없어진다. ACL requirement는
  고정되지만 **partition list가 cdhash로 기록**되고 이건 빌드마다 바뀐다.
  Team ID가 있는 Apple Development 인증서라야 해결된다
- `open` 은 실행 중인 앱을 재시작하지 않고, WKWebView가 `index.html` 을
  캐시한다. `scripts/rebuild-and-run.sh` 를 쓸 것
- TLS는 native-tls가 rustls보다 번들 0.7MB 작고 CPU도 미세하게 싸다.
  단 ureq는 provider를 명시하지 않으면 rustls를 골라 **패닉**한다
